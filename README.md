# Cluster Around and Find Out

This repo contains the documents and code of "Cluster Around and Find Out", a conversational clsutering system that clusters data by following the instructions of the user, specified in natural language.

## Documentation

The documentation (which includes simplifying assumptions, study objective, architectural choices, etc.) is available in the `docs/` folder.

## Setup

To run the system, follow the instructions available in `src/README.md`.
